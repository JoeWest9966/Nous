# map

一个节点一个文件夹，文件夹名 = 节点的 id。**id 永不改变** —— 改名、搬爹、撤销都不动它。
`AGENTS.md` 是你的地盘（也是 agent 进来时自动读的那份）。它是你写第一个字那天才出现的 —— 宿主不铺，之后也永不覆盖。

树里已经没有的节点，文件夹会挪进 `.gone/`，不删。哪天撤销把它带回来，同样的 id 会把它接回家。
