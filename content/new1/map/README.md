# map

一个节点一个文件夹，文件夹名 = 节点的 id。**id 永不改变** —— 改名、搬爹、撤销都不动它。
`agent.md` 是你的地盘，程序只在建文件夹时写一次，之后永不覆盖。

树里已经没有的节点，文件夹会挪进 `.gone/`，不删。哪天撤销把它带回来，同样的 id 会把它接回家。

| id | tree | 名字 | 类型 |
|---|---|---|---|
| `n45` | `N` | N | 组 |
| `n41` | `N/src` | src | 组 |
| `n39` | `N/src/App.tsx` | App.tsx | 块 |
| `n40` | `N/src/utils.ts` | utils.ts | 块 |
