这一页只认编目。编目 = Nous Warehouse 的 models.json（j1900:/opt/Data-001），REST 面 /api/model。本机 ~/.pi/agent/models.json 不在这里，也不从这里读。
  • 名字是唯一键。nw model register 同名同 baseUrl = 覆盖写，同名不同 baseUrl = 硬拒。想换 baseUrl 只能删了再登记。
  • 密钥形状有三种：$ENV 引用 / 字面量 / !命令。列表里字面量永远是 <redacted:…>，真身只在点「密钥」时现拿一次。
  • 推到编目的密钥是明文的，落进 /opt/Data-001/models.json（这个文件在 git 里）。token 闸不展开 $ENV，所以推引用进去必然 401 —— 引用只能手写进文件。
  • 自查 = nw model recheck：编目自己跟上游 /models 比，报新增 / 下线 / 漂移。
  • 删除不可逆，且没有「谁在用」的保护。确认弹窗会先把「改哪个文件、会打 commit、谁还在引用」摆出来，点确认就执行；删掉一条还被配方引用的供应商仓库不会拦你，破绽留到自查和 nw doctor 那层才露。
