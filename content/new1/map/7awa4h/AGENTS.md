# 7awa4h —— 会话鱼骨（作业面）

把 qrd3wh 那一盘会话摆成一张 Ishikawa 图。数据、选择、同步方式跟 `pxbgng`（树视图）
**一模一样**，只是形状不同 —— 那两个页面是同一份东西的两种摆法。

## 映射（为什么骨头是对话）

| 鱼骨上的东西 | 是什么 |
|---|---|
| 鱼头（右侧胶囊） | 这一盘的总数：`N 个会话` |
| 脊 | 没有语义，就是画布的横轴 |
| 每根骨头 | 一个**顶层对话**（没有爹的那个），名字装在自己的圆角框里 |
| 骨头上的刺 | 它的**分叉**，一根刺一个 |
| 刺上的小斜刺 | 分叉的分叉（第三层），降一档灰 |
| 第四层及更深 | 折成一条路径 `A / B`，当成第三层的一根刺 —— 不丢，也不把骨头撑成一棵树 |

骨头上下交替（第 0、2、4 根朝上）。点任何一根刺 / 任何一个框 = 选那个会话，
写回 qrd3wh 的 `/v1/selection`，那边的页面 1.2 秒内自己跟过来；反过来也一样。

## 几何：全是量的

来自 `pele.run/examples/ishikawa` 的真实 SVG 输出 + 深色主题的像素取样：

- 骨头斜 0.48（每往外 1px，往左 0.48）；骨头扎进脊、脊扎进鱼头，各有一个 7×3.4 的实心小箭头
- 刺 18px 水平、间距 27px、第一根离脊 27px
- 刺上的字：14px，**基线压在线上方 5px**（Pele 是 `-27.5` 的线、`-22.6` 的字）；第三层 13.5px + 灰
- 骨头框 34 高、圆角 4、padding 26；鱼头 48 高、右端半径 24
- 框骑在骨头尖上。名字宽、骨头短的时候框会往右越过挂点把脊顶歪 —— 那就把框往左推，
  **不要**把骨头拉长（试过，会变成一根晾衣绳）
- 颜色：底 `#1c1b1a`、字 `#cecdc3`、图标/次文 `#878580`、线 `#75746f`、框底 `#282726`、
  框边 `#403e3c`、强调 `#5b7bd5`

## 改它的注意

- 全是静态文件，没有 `server.js`。
- 布局是手算的（`layout()`），三个不变量别破坏：**框不互相叠**、**骨头尖落在自己框的下沿**、
  **每根横刺的某一端扎在骨头上**。`/tmp` 里那套校验脚本干的就是这件事。
- 图比屏宽就横着滚（`#canvas` 是 `width:max-content`），鱼骨不折行。
- 会话的增删改名都在 qrd3wh 里做，这一页只摆和挑。
