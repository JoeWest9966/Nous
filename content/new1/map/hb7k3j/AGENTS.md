# hb7k3j · session-new —— 新对话的发起页

本块是一个纯静态页面（`index.html`，宿主内置空跑 server 端出去，没有自己的后端）。

## 页面结构

盘面是 **Cynefin**（pele.run/examples/cynefin）的**原路径重绘**，不是仿形：

- 几何：`viewBox 0 0 640 440`，中心 (320,220)，confusion 椭圆 rx88/ry64，
  四域边界、cliff 全是 pele 的 `d` 平移 −8/−44 得来，`preserveAspectRatio="none"` 拉伸填满，
  描边用 `vector-effect="non-scaling-stroke"` 保持像素级粗细。
- 配色：pele 的 dark 主题原变量（Flexoki）—— bg `#100f0f`、盘面与节点填 `#1c1b1a`、
  边 `#403e3c`、正文 `#cecdc3`、次级 `#878580`、accent `#4385be`，
  系列色 s1红 `#d14d41` / s2橙 `#da702c` / s3黄 `#d0a215` / s4绿 `#879a39` / s5青 `#3aa99f`。
  域填充 0.14、中心椭圆 0.18——数值与线上 demo 像素级对齐。
- 字体：站点同款，`-apple-system/Inter` 正文 + `ui-monospace/SFMono` 代码性标签。
- **r1（模型）/ r2（上下文）/ r4（扩展）三域是活的**，各有一颗节点，点开各自的弹窗；
  r3（权限）还是空的：只排标题 + 两行斜体副标题，跟 demo 的空域一个样子 —— 那个字段今天
  在引擎里还没有真东西，画上去就是假的。
- **中央椭圆 = 新对话的出生点**：名字输入 + 创建。
- **一屏无滚动**：`html/body overflow:hidden`，盘面吃满视口；竖屏下椭圆收小、
  域的标题往外侧推（上两域顶、下两域底），保证谁也不盖谁。

## 它做什么

只做一件事：**选配置 → 创建新对话**。

四个域不是四个待开发的功能，是**同一份 agent 配置的四个抽屉**（pi-durable 的 `AgentChange` 就那么几个字段）：

| 域 | 对应字段 | 现在 |
|---|---|---|
| 模型（r1） | `model` + `thinkingLevel` | ✅ 三列铁路图弹窗 |
| 上下文（r2） | `extensions`→sections、`instructions`、`cwd` | ✅ 两个框：技能多选 / 模板单选（`instructions` 还没接） |
| 工具（r4） | `tools` / `modelTools` | ❌ 只有 qrd3wh 那颗「只读」chip |
| 权限（r3） | 没有独立字段，是 hook 层 `beforeTool` 阻断 | ❌ 别做假的 |

- 模型清单来自 `qrd3wh` 的 `GET /v1/models`（只列这台机器真能用的，不列内置目录）。
  清单里每条都带 `thinkingLevels` —— 这个模型真支持哪几档，由 pi-ai 的
  `getSupportedThinkingLevels` 算出来，非 reasoning 模型就是 `["off"]`。
- 选配置走**苹果风格弹窗**：半透明材料（`backdrop-filter`）+ 压暗 scrim +
  从被点节点长出来（`transform-origin` 对准触发点），选中即收回、Esc/点 scrim 原路返回；
  `prefers-reduced-motion` 退化成淡入淡出。
- **模型域**：点节点 → 三列铁路图弹窗（`供应商 │ 模型 │ 思考`，pele railroad 的语法重绘）。
  每列一条规则、每行一支药丸（choice 分支纵向排，首行在主轨道、其余行汇入左右两根锚定竖线），
  高度 = 最长一列的行数 × 40px。宽度装不下时列会摞成行（同一个 `drawRule` 换个位置，
  不是另一套版面）；思考列只在这个模型有得选（档位 > 1）时才出。
  思考档留在这儿是对的：档位是模型的属性，换模型要重新夹。
- **上下文域 = 两个小框，不是一个。** 技能（多选、正文由模型按需 `read`）和模板（单选、
  正文整段每轮都进）是两种决定，各开各的门：`#pickctx` → `#scrim2`，`#pickprompt` → `#scrim4`。
  合成一个弹窗分两段也试过 —— 技能一多，第二段就掉到折线以下，挑模板得先滚过六条技能。
- **两个弹窗共同的规矩**（跟模型弹窗相反的那条）：**不点了就关**。一个「点一下就收回」的窗口里
  塞多选，勾第二个技能时窗口已经没了。都是勾完按「完成」。
- **模板弹窗照扩展那副骨头**：筛选框 / 视图 chip / 右栏类别 / 底栏计数 + 完成。

  | | 语义 |
  |---|---|
  | 形状 | 圆框 = radio，一次一个（正文 7KB；两份互相矛盾的规则一起贴，模型只会挑它喜欢的） |
  | 第一行 | **无模板** = 「一条都不要」的那个真值（`null`），不是额外开关 |
  | 右栏 | **只放人自己建的类别**（词表 − `Basics`），跟扩展同一判据；一条都没有 → 整栏不出现，弹窗回 720 宽 |
  | 视图 | 全部 / `Basics` / 未分类 / 只看已选；跟右栏是同一条轴，一击只有一个亮 |
  | 窄屏 | 右栏横过来变成一排 chip（`.body.has-rail`） |
  | 空态 | 私库一条都没有 → 不摆「无模板」假选项，给一条去模板库的真链接 |
- **模板行是 `div` 不是 `button`**：里面要放「预览」，button 不能套 button。代价是 `Enter`/`Space`
  不会自己变成 click，所以 `#tmplList` 的 keydown 手写了一条；「无模板」那一行没有预览按钮
  （没有正文，一个点了什么都不会发生的按钮比没有更糟）。
- **箭头只移焦点，不落值。** 扫一遍就把模板换掉，是最烦人的那种手滑。`←→` 在清单和类别两栏之间走。
- **预览就地展开**（`<pre class="peek-body">`），不开第三层 scrim：Esc 的层级已经很深了。
  正文按需读 `GET /v1/prompts/file`，读过一次贴住。
- **Esc 收最上面那一层**（`scrim4 → scrim3 → scrim2 → scrim`），不是写死某一个：
  四层弹窗时，写死一个等于另外三个按 Esc 只会响一声。
- **盘面上**：技能框 tag 是 `0/6 ›`，模板框 tag 是 `smart-ass ›`，副标题 `技能 0/6 · 模板 smart-ass`。
  默认值来自私库 `settings.json` 的 `default`，预勾但它不是「已选」。
- **上下文弹窗故意不用铁路图。** 铁路图表达的是语法链（一层嵌一层的依赖：供应商决定模型、
  模型决定档位）；技能和模板是平铺集合，没有谁依赖谁。为版式统一硬套，等于用图讲错话。
- **扩展域**：一族一行，变体缩进挂在下面。族内 **radio**（只能选一个名字），族间独立。
  默认只勾**本体**。

  | 概念 | 数据从哪来 |
  |---|---|
  | 家族（本体） | `GET /v1/extensions` 的 `catalog` ∩ `installed` |
  | 变体（`123@dev`） | 同接口的 `variants[本体名][]` —— ⚠️ **不在 `installed` 里**，那是按本体算的 |
  | 能装的名字全集 | `loadable`（后端给的，含变体 key） |

  **为什么族内必须互斥**：`123` 和 `123@dev` 是同一份代码的两个注册名。一条会话同时装两个，
  就是同一个扩展在同一个进程里跑两遍 —— 工具名、提示词段全撞。这不是「少一个选项」的问题，
  是装着装着就出 bug。所以方框画成圆的，形状本身就说 radio。
  再点一次已选的名字 = 这一族一个都不要（想不装某个扩展，得留这条退路）。
- **类别分两个地方放，不是一条横条**：顶部只摆**系统视图**（全部 / 内置类别 / 未分类 /
  只看已选），人自己建的类别摆在**右栏**（`#extRail`）。分工抄 vbe4pt。
  - **栏里不混系统项**：把「全部 / 未分类 / Basics」掺进右栏，「我自己建了什么」就再也看不出来了；
    反过来把二十个自定义类别摊到顶栏，那行胶囊会滚成一条没头的带子。
  - **顶部与右栏是同一条轴**（「给我看哪些」），一击只有一个亮：点右栏类别 → 顶部全灭
    （`extView = null`）；点顶部 → 右栏灭。两套叠着亮，等于让人在脑子里做交集。
    **只看已选**是另一条轴（「我挑过的」，不是「哪些」），所以它叠着用。
  - **右栏的读法借自模型弹窗**：列头 + 一根竖轨 + 缩进引线，窄了**栏变条**（`≤760px`）——
    跟模型那边「装不下就把列摞成行」是同一套办法，不是另画一版。
    ⚠️ 换方向只改 `#extRailList` 这一层：把 `flex-direction:row` 写在 `.rail` 上，
    只让「装着一列按钮的 div」变成横排，按钮照样竖着摞（踩过）。
  - **一条自定义类别都没有 → 整栏不出现**，弹窗退回 720 宽（`has-rail` 类在 `.body` 和 `.sheet`
    上同时切）。没内容的地方不白占 176px。`.rail[hidden]` 得手写一句 `display:none`
    —— `hidden` 是 UA 的 display:none，被自己的 `display:flex` 盖掉了。
  - **零计数的类别保留但灰掉**（词表里有、没挂扩展）：建了看不见比灰着更糟。
  - 右栏**只筛不管建**，底下一行 `+ 新建类别：去扩展页`（地址从 `ctx` 取 vbe4pt）。
  - 分组标题只在「全部」视图里出，且按**主归属**（`category[0]`）分组：多类别的扩展在
    全部视图里只出现一次。重复行会让同一个扩展有两个勾选框 —— 那是 bug 温床，不是功能。
  - 筛选是**视图**，一个字节都不动 `pickedExtensions`；每次打开弹窗回「全部」——
    藏着的筛选就是「我的扩展不见了」。
  - 空状态按「哪一层挡住的」给出口：搜不到 → `清空搜索`，只看已选 → `取消「只看已选」`，
    看错了类别且别处有 → `全部类别里有 N 个 ›`。在错的类别里搜一个存在的扩展，
    读起来就跟它不存在一样。
  - 键盘两栏之间用 `←→` 走（列表 → 右栏，右栏 → 回到选中那行），跟模型弹窗「↑↓ 列内、
    ←→ 换列」一个手感。
- **默认只勾 `Basics` 类别的本体**（`DEFAULT_CATEGORY`），其余一个不勾 —— 人可以自己再取消，
  也可以自己勾上别的。变体**永不在默认值里**：那是「我正在试的那版」，不该由默认值替人做决定。
  - 类别是**树**：`Basics/234` 这种子类别也算 Basics（词表里真的存在），所以判据是
    `=== wanted` 或 `startsWith(wanted + "/")`，别拿 `===` 一刀切。
  - **Basics 里一个都没有 → 一个都不勾**，不偷偷兜底勾 `nous`/`skills`：那样这条规则就是假的。
    后果是发出去的 `extensions: []`，也就是「一个都不要」—— 那是有意义的表达，不是错误。
  - 默认勾什么，写在**盘面的副标题**里（`已装 4 个 · 选中的 2 · 默认 Basics`），不放弹窗底部：
    开弹窗之前就该看得见。弹窗底部只留计数和「完成」。
- **装载失败的变体不给勾**（`load.state === "failed"` 或 `installed: false`）：灰掉 + 写明原因。
  勾了到会话里就是装载失败，而那种失败没人能自己诊断。
- 变体行写**来处**：本机给 `分支 ext/123-dev`，参数变体给 `参数 {…}`，仓库里没绑的给 `仓库里 · 同代码`。
  元信息一行灰字，不抢本体那行的位置。
- 一条都没装时，弹窗里给的是**真能走的链接**（技能去 `68kazk`、模板去 `6ysg01`，地址从 ctx 拿、不拼死），
  不是「暂未开放」四个字。
- 点「创建」→ `POST qrd3wh /v1/sessions`，带 `{model, thinkingLevel, skills?, template, name?}`，
  四样在**同一个 commit** 落定（不是先建再 configure），成功后再 `POST /v1/selection`。
  `template` **总是发**：`null` 也是有效值（明确不要）。省掉它服务端会去用私库的默认模板 ——
  那就会出现「我点了无模板，它又给我塞回来」。
  服务端回的 `thinkingLevel` / `skills` / `template` 是**生效值**；`missing[]` / `missingTemplates[]`
  是「勾了但没装、已跳过」——
  必须显示出来，不然人会以为勾上了。
- **键盘流**：焦点是**列**不是项。`↑↓` 列内移动（到头就停，不绕圈）、`←→` 换列、
  `↵` 就是「点它」（走同一个 `actOn`，不写第二套判断）、`Esc` 收回、
  在药丸上直接打字 = 回搜索框接着打、从最顶上再 `↑` = 回搜索框。
  焦点存 `kb`（`{on,col,row}`）而不是靠 `document.activeElement`：`renderDiagram()`
  每次都把整个 `<svg>` 重建，真焦点会跟着旧节点一起消失 —— 换个模型列表就「键盘失忆」。
  重画后 `paintKb()` 把环钉回同一个格子并 `scrollIntoView({block:"nearest"})`。
  视觉上键盘环比 hover 重一档（`stroke-width:2` + 一圈光），暗底上分得出「我刚按到哪儿」。

### 「面板上写的 = 实际跑的」

这条是弹窗的唯一硬要求，别为了省事破它：

- **档位由模型能力决定，不由我们决定。** 面板只画 `thinkingLevels` 里那几档；换了模型，
  本地档位立刻按 pi-ai 同一套顺序（先往上找、再往下找）重新夹 —— 和服务端那次夹**同序**，
  否则就会出现「面板显示 A、存进去是 B」。
- **认服务端回来的值。** 创建后拿 `created.thinkingLevel` 覆盖本地 state，副标题也跟着它走；
  档位默认值是 `off`（对齐 pi-durable 的 `state?.thinkingLevel ?? "off"`），
  所以「没选」显示的就是真会跑的，不是「不知道」。
- 服务端还会再夹一遍（客户端发的值不可信），两边夹的规则一字不差，
  所以正常路径上第二次夹什么都不改。

## 它不做什么

- **没有对话列表** —— 那是兄弟块 `pxbgng`（session.2）的事。
- **没有对话内容** —— 那是父组 `qrd3wh`（session 引擎）的事。
- 不存任何状态：没有 `data/`，本页选中哪个模型只是页面内的临时选择；
  「默认模型」是 `qrd3wh` 的状态，存在它的 `data/default-model.json`。

## 对话的概念

fork 和 new sessions 都是「开启一个新对话」。区别只在入口：
本块发的是顶层新对话；fork 从某条历史长子枝，走 `qrd3wh` 的 `/v1/sessions/:id/fork`。

## 块间规则

- 地址只从 `__nous/ctx` 拿（先按 id `qrd3wh`，认不出按组名 `session` 找）。
- 只走 HTTP，不 import 别的块、不读别的块文件夹。
- 链接写相对路径，页面才能 `cp -r` 走了照样跑。
