# 3699b9 · New-Template —— 会话预设的管理页

**一条预设 = 一组「开这条会话时用什么」的引用**（模型 / 思考档 / 技能 / 扩展 / 模板 / 只读）。
它不装内容：正文在 `Nous-prompts`，技能在 `Nous-skills`，扩展在 `Nous-extend`，模型在编目。
它只说「这次用这几个」—— 所以这一页上的每个 chip 都是一个**指向别处**的指针。

兄弟块 `hb7k3j`（New-Manual）是**现场挑**一套配置；这一块是把那套存下来，下次点一下就开。

## 为什么只剩发静态文件

数据不走这个进程。页面自己去问 `qrd3wh` 的 `GET /v1/presets`，地址从宿主的 `__nous/ctx`
里找 —— **这一块里不拼任何绝对路径，也不跑 git**。所以 `server.js` 只做一件事：把
`public/` 发出去（剥 `NOUS_SELF`、目录穿越 403、目录 → `index.html`、`cache-control: no-store`）。

| 谁 | 干什么 |
|---|---|
| 本块 | 发静态文件 + 在浏览器里画 |
| `qrd3wh` | 唯一写入口 + **唯一校验口**（`/v1/presets*`、`POST /v1/sessions {preset}`） |
| `Nous-presets` 仓 | 唯一真相：`<名>/preset.json`（+ 可选的 `PRESET.md`） |

**这一块没有 `data/`、没有配置、没有 token、没有后端状态。** 要写 `NOUS_DATA` 的东西就说明它
不该在这一页。

## 页面上每一栏在说什么

- **顶栏**：`HEAD` + 同步 chip（`已同步` / `有未提交改动` / `N 个提交没推` / `远端多 N 个` /
  `没有远端（只在本地）`）；`repo.error` 有值时那行变红并显原文 —— git 失败要看得见，不是白屏。
- **左栏类别**：缩进的类别树（`/` 分段，父级计数含后代且按预设去重），父级筛出整枝；
  每行 `⋯`（右键 / 长按 520ms）三项：新建子类别 / 编辑名称（填**全路径**，改前缀 = 搬家）/
  删除整枝（确认框写明带几条预设、几个子级）。零计数的类别保留但灰掉。
- **筛选栏**：全部 / 未分类 / 未发布 / 引用失效 / 写坏了 / 已归档。**非零才出现，图例就是筛选**，
  不另写说明。**「全部」不藏坏账** —— 藏着的坏账等于没有账。
- **卡片**：字母砖（色相由名字 hash）+ 名字 + 摘要 + 类别 chip + **引用 chip 行** + `▶ 启动`。
  chip 全读服务端算的 `resolved`，一个都不自己推：

  | chip | 三种长相 |
  |---|---|
  | 模型 | `自动 · <设备默认>`（灰）/ `provider/modelId` / 红 |
  | 技能 / 扩展 | `默认`（灰，键缺席）/ `都不要`（`[]`）/ `N 条` / 红 |
  | 模板 | `默认`（灰）/ `无`（`null`，正常色）/ 名字 / 红 |

- **卡状态**（优先级 `failed > invalid > unpublished > ok`，`model.js` 的 `cardState()`）：

  | 状态 | 长相 | 意思 | 能启动 |
  |---|---|---|---|
  | `ok` | 实边 | 好的 | ✅ |
  | `unpublished` | 琥珀虚线 | 盘上有、HEAD 没有 | ✅ |
  | `invalid` | 红边 + 点名哪条引用 | 引用的东西没了（修**那边**） | ❌ |
  | `failed` | 红边 + `specError` 一行 | 这条自己写坏了（修**这里**） | ❌ |

- **详情**（点卡开半扇浮层，不换页）：摘要 / 说明（`PRESET.md`，没有就不摆这一节）/ 类别
  （唯一可改的地方）/ **引用一览**（每个引用一条，失效的带「去那边 ›」链接 —— 地址从 ctx 拿，
  拿不到就只是文本）/ 仓库（发没发布、绝对目录）/ 底部 `归档 · 编辑 · ▶ 启动`。
- **编辑抽屉 = 一块盘面**（版式照 `hb7k3j`，720px 半扇不变）：四个域各一颗节点、中央一颗椭圆。
  一个 **盘面** tab + 一个 **JSON** tab，编的是同一份 `preset.json`。

  | 域 | 字段 | 点开是什么 |
  |---|---|---|
  | 模型（左上） | `model` + `thinkingLevel` | 铁路图：供应商 › 模型 › 思考（含「缺省」一档）|
  | 上下文（右上） | `skills[]` + `template` | 两个框各开一个门：技能集合 / 模板单选 |
  | 扩展（左下） | `extensions[]` | 一族一行，变体缩进；族内互斥 |
  | 权限（右下） | `readOnly` | 没有弹窗，点一下就是切换（只有一个布尔，套窗就是仪式）|
  | 中央椭圆 | `name`（只读显示）| `启动` + `保存`（发布在头部）|

  - **三态在弹窗顶上那排 chip，不在盘面上**：`跟随默认` / `都不要` / `挑几个`。盘面上的框只显示
    **结果**（`跟随默认` / `都不要` / `3 条`）。为什么不能折成两态：`跟随默认` = 这个键**根本不写**，
    跟「勾满现在的全部」长得一样、后果相反 —— 后者以后多了技能不会自动进来。这一条丢了就是
    静默改写老 preset（打开一条 `跟随默认` 的，存一次就钉死了）。
  - **点一条就自动切到「挑几个」**：档位是现在是什么，不是一道要先过的闸。
  - 技能 / 扩展弹窗照扩展那副骨头：筛选框 / 视图 chip（`全部` `Basics` `未分类` `只看已选`）/
    右栏类别（只放人自己建的，一条都没有整栏不出现）/ 底栏计数 + 完成。模板多一样：行内 `预览`。
  - **`无模板` 恒第一行**，它就是 `template: null`（「明确不要」），不是额外开关。
  - **仓里有、清单里没有的名字要留一行**（「仓里有 · 这台机器上没装成」）：静默消失等于悄悄改配置。
  - 切 tab：盘面 → JSON 立刻生成；JSON → 盘面只在能 `JSON.parse` 时回填（非法 JSON 上回填等于猜）。
  - 校验问服务端（`POST /v1/presets/validate`，600ms debounce），**这一页不写第二套规则**。
  - **保存和发布是两个按钮，不许合并**：`保存`在中央椭圆（`PUT /v1/presets/file`，带 etag，撞了 409）；
    `发布`在头部（`POST /v1/presets/publish`，闸 + 重扫 + commit + push）。发布成功后**重读这个文件**
    （基线跟着 HEAD 走了，否则差异视图还在跟旧 HEAD 比）。
  - **`启动` = 先落盘再开对话**：拿没存过的东西开会话，等于盘上和屏幕上不是一回事。落盘失败就不启动。
  - **Esc 只收弹窗那一层**：四个弹窗挂在 `window` 的**捕获**阶段，`stopPropagation()` 之后才轮到
    `document` 上那条（关抽屉 / Alt+D / ⌘S）。写在冒泡里的话，一按 Esc 连抽屉一起没了。
- **启动**：确认框（名字预填 `<预设> MM-DD HH:MM` / 生效配置一览 / 会跳过什么）→
  `POST /v1/sessions {preset, name}`（**同一个 commit 落定**）→ `POST /v1/selection` →
  **新标签页**打开会话引擎。不在这一页内嵌聊天，也不在本页跳走（会丢掉树的展开 / 滚动 / 撤销栈）。
  服务端回来的 `missing[]` / `missingTemplates[]` / `missingExtensions[]` 必须显 —— 不显就是
  「人以为勾上了，其实没有」。

## 三条不许踩

1. **不复刻服务端的闸。** 名字字符集、撞目录、撞 `.archive/`、摘要非空、引用存在性、
   档位在不在那台模型的档位表里 —— 全部由 `qrd3wh/presets.js` 一处判定。这一页只播报服务端
   那一行原文，不重写、不加前缀。
2. **改完要重扫。** 写端点自己会 `presets.load()`；命令行里改了 `preset.json` 之后点「重扫」。
   不 load 的话面板显示新预设、建会话时还是看不见它 —— 两份真相就是这么长出来的。
3. **面板上写的 = 实际跑的。** chip / 详情 / 启动确认框里的模型、档位、模板一律来自
   `resolved`（服务端算的），不来自我们发上去的那份 spec。这条破了，这一页存在的意义就没了。

## 不做的事

- **没有变体。** 预设只有一条生命轴 —— 仓里的版本。要「同一条预设的分支版」就是两条预设。
- **没有复制。** `cp -r <名> <新名>` 加改一行 `name` 就是全部，不为它开一个按钮。
- **没有改名。** 目录名 = `name` = 会话里的键。想换名字就归档旧的、建新的。
- **没有默认预设。** 这一页的启动永远是显式点击；「默认」会让「新建对话」随「谁最后点了哪条」而变。
- **不内嵌聊天。** 开会话就是开新标签页。
- **不碰 git remote / 凭据。** 「专属私仓」的 origin 归你自己配；这一页只播报（脱敏），本地单用户也合法。
