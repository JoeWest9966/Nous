# pxbgng —— 对话列表

一页只干一件事：把 qrd3wh 左列那棵会话树整页铺开，挑谁，qrd3wh 就是谁。

## 数据从哪来

不碰 qrd3wh 的 sqlite，也不翻它的 `data/`。全部走它的 HTTP：

| 用途 | 请求 |
|---|---|
| 地址 | 宿主的 `__nous/ctx` → `blocks[].url`（页面上一个 `/p/...` 都没拼） |
| 列表 | `GET  <qrd3wh>/v1/sessions` |
| 现在是谁 | `GET  <qrd3wh>/v1/selection` → `{ id, at }` |
| 换人 | `POST <qrd3wh>/v1/selection { id }` |

`at` 是那条选择的版本号：两边都拿它认「这条我见过没有」，谁改都不打架。

## 同步是怎么发生的

这一页不通知谁，只改 qrd3wh 盘上那一个值；qrd3wh 的页面自己 1.2 秒轮询一次
`/v1/selection`，发现 `at` 变了就切过去。反过来也一样 —— 在 qrd3wh 左列点一下，
这一页的状态是轮询跟上来的，不是谁去告诉它的。

所以两个页面**同时开着**才对得上；关掉的那一边下次打开时读到的仍是最后一次选择
（存在 qrd3wh 的 `data/selection.json` 里）。

## 改它的注意

- 全是静态文件，没有 `server.js` —— 宿主的内置空跑 server 直接端出去，不需要 `npm start`。
- 要删的节点、要改的名字，回 qrd3wh 里做；这一页只负责挑。

## 外观从哪来

照 Pele 的 `treeView`（pele.run/playground，`treeView-beta`）做的，几何是量出来的，不是猜的：

- 16px Inter、28px 行距；图标 16px、描边 1.5；标签离图标 6px
- 缩进 20px，图标落在 `8 + d*20`，引导线在 `15 + 20k`（= 图标左缘 + 7）
- 引导线 1px；只有**最后一个孩子**那里拐 4px 圆角（Pele 的 path 也是这么写的：
  中间那行是 `M15,50H23` 直穿，最后一行才是 `Q15,78 19,78`）
- 图标就是它两个退化 glyph：折角文件 / 夹子（`material-icon-theme` 没装时都长这样）。
  有分叉的对话画成夹子 + 加粗，跟「目录是容器」同一个道理
- 颜色取自它深色主题的实际输出：底 `#1c1b1a`、字 `#cecdc3`、图标/次文 `#878580`、线 `#3f3d3a`、强调 `#5b7bd5`

加粗、颜色、圆角都能改；**行距和缩进别动**——那三个数是这套皮看起来「像文件树」的全部原因。
