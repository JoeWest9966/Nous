# 移动端这一页

手机上读一份文档，这件事本身应该安静。标题在顶上，正文在下面，别的东西都退到边上。

## 这一块是什么

一块就是一块。它有自己的文件夹、自己的进程、自己的文档。**没有「有代码才有页面」这回事** —— 那会让宿主有权替块当页面。

- 名字是给人看的，`id` 是给机器看的
- 改名不动 `id`，撤销也不动
- 面积不等于值：等大格子 + 中间的数字 + 底下的比例条

## 一个例子

```js
const cols = clamp(1, Math.floor(w / 140), maxCols(w));
```

> 装不下就往下长，只有最外层滚。
