文档 —— 十个方案

一个节点不止一份 .md。十格共用同一份假数据（4 篇： AGENTS.md + 3 篇自己的），也只回答同一个问题：「我要在其中一份上写两行字」 —— 用你最少的动作做到。每格都能真的打字、切文档、新建、删除、恢复：状态走 「编辑中 → 正在保存… → 已保存」，全在内存里，一个字节都不落盘。 AGENTS.md 是 coding agent 进目录时找的那一份 —— 它在任何一条路上都拿不到删除入口，删掉的文档只是挪进「最近删除」，能恢复。 头上的 桌面 / 手机 开关是全局的，每张卡片自己也能单独切：手机形态是 375×812 的真实外框，外框里页面真的重排（侧栏变抽屉 / 变底部 sheet / 变全屏列表页）， 不是把桌面版缩小。Esc 关掉任何浮层、对话、输入框，未提交的编辑不丢。

看的时候重点看这几件事

  • 在 设计.md 里打两个字，别等它保存完就切到 notes.md： 正文必须换成 notes 那一份，左上角状态字说的是 notes 的状态。再切回去，那两个未保存的字 还在 —— 串台就是 bug。
  • AGENTS.md 在每一格里都拿不到删除入口：列表里的 ✕、标题栏的 ⋯、 ⌘K 面板里的行、08 的左滑手势 —— 四条路上都不许出现。真功能里它只能改。
  • 删掉一份（叫「移到最近删除」，因为它确实只是挪进 map/<id>/.trash/）： 它出现在「最近删除」分组里，能恢复。确认卡片默认焦点在取消， Esc 等于取消，destructive 那个按钮是红的、在左边。
  • 切到手机形态：外框里真的重排了（不是缩小），行高 ≥ 44px，输入框字号 ≥ 16px， :hover 不残留。01 和 06 是同一件事的两个极端，02 和 05 也是，03 和 09 也是 —— 摆在一起是为了做减法，不是选最多的那个。
