`{{tree}}` —— 一个**组**（容器），不是 app。

| | |
|---|---|
| 组 id | `{{id}}`（也就是这个文件夹的名字，**永远不变**） |
| 在树里 | `{{tree}}` |
| 宿主里的地址 | `/p/{{board}}/{{id}}/` |
| 这个文件夹 | `content/{{board}}/map/{{id}}/` |

组的作用是装别的块。它自己默认是一张空白页 —— 要它也有界面，
往这个文件夹里放 `index.html` 或 `package.json` 的 `scripts.start`，同一地址立刻归它。

## 你在哪

你被启动在这个文件夹里。**你有且只有这个文件夹**。
宿主的树（`content/{{board}}/tree.json`）、它里面的块、外面的 `__nous/` 都不归你管。

## 三条不许

1. **块之间只走 HTTP**：不 import 别人的代码，不读别人的文件夹。
2. **不自己拼 `/p/<board>/<id>`**：地址只从 `ctx` 和 `resolve` 来。
3. **不碰 `__nous/`** 和 `tree.json`（宿主的真相，只有四个字段）。
