## 你在哪

你被启动在这个文件夹里，任务是把它做成（或者继续做）一个 app。

## 宿主给什么

起这个块时会给四个环境变量。**端口不许写死**，一律听 `PORT`：

| 变量 | 意思 |
|---|---|
| `PORT` | 必须监听它 |
| `NOUS_DATA` | 持久化只写这里（= 本文件夹下的 `data/`）。`cp -r` 走，数据就跟着走 |
| `NOUS_ORIGIN` | 宿主的地址，跨块调用时用它 |
| `NOUS_SELF` | 我在宿主里叫什么：`/p/{{board}}/{{id}}` |

页面里的地址一律写**相对路径**（`api/health`，不是 `/api/health`）。
理由：这块要能被 `cp -r` 出去独立跑，绝对路径一写就废。

## 怎么让它有页面

**你写什么，它就有什么。** 宿主不会预先铺一份模板 app —— 那会让人以为这块已经有功能了。

| 你放进去 | `/p/{{board}}/{{id}}/` 变成 |
|---|---|
| 什么都不放 | **白板**（空白页，`view-source` 里也是空的） |
| `index.html`（或任何静态文件） | 那些文件原样端出去 |
| `package.json` 里有 `scripts.start` | 跑你自己的服务，宿主只反代 |

所以「让它动起来」= 写一个 `package.json`：

```json
{ "type": "module", "scripts": { "start": "node server.js" } }
```

再写 `server.js`（听 `PORT`）和 `public/index.html`。零依赖就够了，`npm install` 不归宿主管。

## 文件夹里有什么

| | |
|---|---|
| `AGENTS.md` | 这一份。宿主建文件夹时写过一次，之后**永不覆盖** |
| `public/` | 你自己建的：对外的静态文件 |
| `server.js` | 你自己建的：后端 |
| `package.json` | 你自己建的：有 `scripts.start` = 宿主把它当 app 跑 |
| `data/` | 你自己的数据，等价于 `NOUS_DATA` |
| `*.md` | 你写的文档，`…/__nous/doc` 里能看能改（`AGENTS.md` 只能改，删不掉） |

## 宿主留了几个地址

- `…/__nous/doc` 文档页（菜单里那条「文档」；`map/` 里的 md 都在那儿）
- `…/__nous/ctx` 我是谁、邻居有谁、它们在哪（JSON）
- `…/__nous/resolve/<id>` 问某个块现在的绝对地址

## 三条不许

1. **块之间只走 HTTP**：不 import 别人的代码，不读别人的文件夹，不信任别人的 `data/`。
2. **不自己拼 `/p/<board>/<id>`**：地址只有一个来源，就是 `ctx` 和 `resolve`。
3. **不碰 `__nous/`**（宿主的）和 `tree.json`（宿主的真相，只有四个字段）。
