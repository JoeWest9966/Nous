## 你在哪

你被启动在这个文件夹里，任务是把它做成（或者继续做）一个 app。
**你拥有且只拥有这个文件夹。** 宿主的树（`content/{{board}}/tree.json`）、
别的块、`__nous/` 都不归你管 —— 也不许去改。

## 宿主给什么

起这个块时会给四个环境变量。**端口不许写死**，一律听 `PORT`：

| 变量 | 意思 |
|---|---|
| `PORT` | 必须监听它 |
| `NOUS_DATA` | 持久化只写这里（= 本文件夹下的 `data/`）。`cp -r` 走，数据就跟着走 |
| `NOUS_ORIGIN` | 宿主的地址，跨块调用时用它 |
| `NOUS_SELF` | 我在宿主里叫什么：`/p/{{board}}/{{id}}` |

页面里的地址一律写**相对路径**（`api/health`，不是 `/api/health`）。
理由：这块要能被 `cp -r` 出去独立跑，绝对路径一写就废。

## 文件夹里有什么

| | |
|---|---|
| `public/` | 对外的静态文件。浏览器看到的就是它 |
| `server.js` | 后端：端 `public/`、处理 `/api/*` |
| `package.json` | 有 `scripts.start` = 宿主把它当 app 跑 |
| `data/` | 你自己的数据，等价于 `NOUS_DATA` |
| `ADR` / `docs/` | 你后来自己加的，宿主不知道也不管 |

## 宿主留了几个地址

- `…/__nous/doc` 笔记本（面板里能看到）
- `…/__nous/ctx` 我是谁、邻居有谁、它们在哪（JSON）
- `…/__nous/resolve/<id>` 问某个块现在的绝对地址

## 三条不许

1. **块之间只走 HTTP**：不 import 别人的代码，不读别人的文件夹，不信任别人的 `data/`。
2. **不自己拼 `/p/<board>/<id>`**：地址只有一个来源，就是 `ctx` 和 `resolve`。
3. **不碰 `__nous/`**（宿主的）和 `tree.json`（宿主的真相，只有四个字段）。
