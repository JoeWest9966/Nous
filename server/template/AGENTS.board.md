## 它是干什么的

默认空着 —— 打开就是一张空白页。它存在的意义是给这盘留一个**首页的位置**：

- 想要一块全盘仪表盘：往这里放 `package.json` 的 `scripts.start`，
  `/p/{{board}}/{{id}}/` 立刻归你自己的代码；
- 只想留一句话：就写在这个文件里，它是这盘的笔记。

整盘的结构不在这儿 —— 在 `content/{{board}}/tree.json`（只有四个字段的真相）。
**那个文件不归你改。**

## 盘里有什么

`content/{{board}}/map/<id>/` 一个节点一个文件夹，里面是它的 `AGENTS.md`、
（如果是个 app）`package.json` / `server.js` / `public/` / `data/`。
`map/.gone/` 是删掉的节点，没删内容，撤回得回来。

想知道全盘有谁、它们各自在哪：`/p/{{board}}/{{id}}/__nous/ctx`。

## 三条不许

1. **块之间只走 HTTP**：不 import 别人的代码，不读别人的文件夹，不信任别人的 `data/`。
2. **不自己拼 `/p/<board>/<id>`**：地址只从 `ctx` 和 `resolve` 来。
3. **不碰 `__nous/`**（宿主的）和 `tree.json`（宿主的真相，只有四个字段）。
